# traffic-cop — logo guidelines

## 1. The logo

**Idea:** a peaked police cap whose band carries a traffic light — the cop and the traffic in one mark.

| Version              | File                             | Use for                                         |
| -------------------- | -------------------------------- | ----------------------------------------------- |
| Horizontal (primary) | `traffic-cop-horizontal.svg`     | README header, website nav, anything wide       |
| Stacked              | `traffic-cop-stacked.svg`        | square spaces: social cards, slides, stickers   |
| Symbol               | `traffic-cop-symbol-color.svg`   | avatars, icons, when the name is already nearby |
| Symbol, small cut    | `traffic-cop-symbol-small.svg`   | 32 px and below (no dashes, wider gaps)         |
| Wordmark             | `traffic-cop-wordmark.svg`       | rare: when the symbol is shown elsewhere        |
| App icon             | `traffic-cop-app-icon-color.svg` | large icon tiles (≥ 64 px)                      |

One-colour, reversed and PNG versions are in `symbol/`, `horizontal/` and `png/`.
Web icons (favicon.ico, favicon.svg, apple-touch-icon, PWA icons, `site.webmanifest`) are in `symbol/`; paste
`symbol/head-snippet.html` into the page `<head>`.

## 2. Clear space

Keep a clear zone of **1 × band height** (the height of the dashed band) around the logo on all sides. It scales with
the logo.

## 3. Minimum size

| Version              | Screen      | Print      |
| -------------------- | ----------- | ---------- |
| Horizontal           | 120 px wide | 30 mm wide |
| Stacked              | 96 px wide  | 25 mm wide |
| Symbol (with dashes) | 32 px       | 10 mm      |
| Symbol, small cut    | 16 px       | 5 mm       |

Below 32 px, always use the small cut — the dashes fill in.

## 4. Colour

| Name         | HEX       | RGB        | CMYK (approx.) |
| ------------ | --------- | ---------- | -------------- |
| Police navy  | `#16233F` | 22 35 63   | 65 45 0 75     |
| Signal red   | `#F04A3E` | 240 74 62  | 0 69 74 6      |
| Signal amber | `#F2B33D` | 242 179 61 | 0 26 75 5      |
| Signal green | `#34C26A` | 52 194 106 | 73 0 45 24     |

- Navy on white: 15.6:1 contrast. On the navy band: red 4.3:1, amber 8.4:1, green 6.7:1.
- **The signal colours are only for the three dashes**, always red → amber → green from back to front (the cap faces
  forward: green is "go"). Never use them for text or the cap.
- Approved pairs: full colour on white · white cap with signal dashes on navy · black on white · white on black.
- No Pantone match is specified yet; match the CMYK values on a print proof.

## 5. Typography

- Wordmark: **Barlow SemiBold**, lowercase, converted to outlines. Barlow was designed after California highway signs.
- Licence: SIL Open Font License 1.1 (free for logos). Source: <https://github.com/jpt/barlow>.
- Never retype the wordmark — use the files.

## 6. Don'ts

Don't stretch, squash or rotate · don't recolour outside the palette · don't use the signal colours outside the dashes · don't add shadows,
outlines, gradients or effects · don't rearrange or resize the parts of a lockup · don't place on busy backgrounds
without a navy or white container.
